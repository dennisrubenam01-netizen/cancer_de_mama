# 🔬 Cancer ML Dashboard

Dashboard interactivo para clasificación de cáncer de mama usando el **Wisconsin Breast Cancer Dataset**.

## 🚀 Demo
[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io)

## 📊 Modelos incluidos
- **SVM** (RBF Kernel)
- **Red Neuronal** (MLP)
- **Árbol de Decisión**
- **K-Means** (clustering no supervisado)

## 📁 Estructura
```
├── dashboard.py       # App principal de Streamlit
├── cancer.csv         # Dataset Wisconsin Breast Cancer
├── requirements.txt   # Dependencias
└── README.md
```

## ▶️ Correr localmente
```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
